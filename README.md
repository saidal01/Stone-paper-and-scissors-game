# 🪨📄✂️ Stone Paper Scissor Game

A simple Python implementation of the classic **Stone–Paper–Scissor** game where you play against the computer.

---

## 🎮 How It Works
- The computer randomly chooses between **Stone (1)**, **Paper (2)**, or **Scissor (3)**.
- You enter your choice:
  - `s` → Stone  
  - `p` → Paper  
  - `ss` → Scissor  
- The program compares your choice with the computer’s and declares the winner.

---

## 🛠 Requirements
- Python 3.x installed on your system
